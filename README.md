# Electrical Service Connections

Static lead-connection landing page for `electrical-services.site`, designed to explain the service and send visitors to the supplied MarketCall phone number.

Files:
- `index.html` — responsive landing page and required service disclaimer.
- `CNAME` — GitHub Pages custom domain.
- `ad-copy.txt` — proposed text ad creative.
- `ad-preview.png` and `ad-preview.pdf` — clearly labeled proposed preview, not a Google Ads dashboard screenshot.
- `keywords.txt` — proposed exact and phrase match keyword list plus negatives.

The page does not claim to be a contractor, guarantee service, or claim providers have specific credentials. Visitors are told to verify licensing and insurance with the contractor they hire.
